## 🚀 LANCER MAINTENANT - Hinos IA avec Pi Network

### ⚡ En 3 Étapes

**Étape 1**: Démarrer l'app
```bash
npm run dev
```

**Étape 2**: Aller à `/settings`
```
http://localhost:3000/settings
```

**Étape 3**: Tester
```
✅ Cliquer "Connecter Wallet"
✅ Choisir un plan d'abonnement
✅ Effectuer un paiement (simulé en Sandbox)
```
