## ⚡ 5 Minutes pour Démarrer - Wallet Pi & Paiements

### 🎯 Objectif
Connecter votre wallet Pi Network à Hinos IA et effectuer votre premier paiement en 5 minutes.

---

## ✅ Checklist Pré-Démarrage

Avant de commencer, vérifiez que:
- [ ] Vous avez un compte Pi Network
- [ ] Pi Browser est installé OU l'extension Pi Network fonctionne
- [ ] Vous avez au moins 6π pour tester un abonnement
- [ ] JavaScript est activé dans votre navigateur

---

## 🚀 Démarrage (Minuteur: 5 min)

### Minute 1️⃣: Accéder à Hinos IA

```
1. Allez sur votre application Hinos IA
2. Cliquez sur "⚙️ Paramètres" en haut à droite
3. Vous verrez l'onglet "Wallet"
```

### Minute 2️⃣: Connecter votre wallet

```
1. Dans l'onglet "Wallet":
   - Cliquez sur "Connecter Wallet Pi Network" (bouton bleu)
   
2. Une popup d'authentification Pi Network s'affiche:
   - Entrez votre PIN Pi Network
   - Acceptez les permissions demandées
   
3. ✅ Votre profil s'affiche automatiquement!
```

### Minute 3️⃣: Vérifier votre solde

```
1. Vous verrez maintenant:
   - 👤 Votre nom d'utilisateur
   - 📍 Votre adresse wallet (0x...)
   - 💰 Votre solde en Pi (ex: 125.50π)

2. Facultatif: Cliquez "Copier" pour copier votre adresse
```

### Minute 4️⃣: Choisir un plan d'abonnement

```
1. Allez à l'onglet "Abonnement"
   
2. Vous verrez 2 plans:
   
   📦 PRO (5.99π - 7 jours)
   └─ Parfait pour tester
   
   ⭐ PREMIUM (19.99π - 30 jours)
   └─ Notre meilleur plan
   
3. Cliquez "S'abonner maintenant" sur votre plan préféré
```

### Minute 5️⃣: Effectuer le paiement

```
1. Une modale s'affiche avec les détails du paiement:
   - Plan sélectionné
   - Montant en Pi
   - Bouton "Approuver"

2. Cliquez "Approuver":
   - Pi Network confirme votre identité
   - Vous confirmez le montant
   
3. Saisissez le TXID reçu:
   - Copiez-collez le TXID dans la modale
   - Cliquez "Confirmer"
   
4. ✅ Paiement réussi!
   - Un message de succès s'affiche
   - Votre abonnement est actif
```

## ❓ Aide Rapide

| Problème | Solution |
|----------|----------|
| Le bouton "Connecter" ne fonctionne pas | Rechargez la page, vérifiez Pi Browser |
| Le solde n'apparaît pas | Cliquez "Actualiser" ou reconnectez-vous |
| La transaction n'est pas confirmée | Attendez 1-2 min, vérifiez le TXID |
| Je ne vois pas les fonctionnalités premium | Vérifiez que votre abonnement est actif |
