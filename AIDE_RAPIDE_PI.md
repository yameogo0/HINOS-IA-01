# 🆘 AIDE RAPIDE - Questions les Plus Fréquentes

## ❓ J'ai peu de temps, par où commencer?

**Réponse:** 30 secondes pour lancer!
```
1. npm run dev
2. http://localhost:3000/settings
3. Connecter Wallet → 50π fictifs ✅
```

---

## ❓ C'est gratuit?

**Réponse:** OUI! Mode Sandbox = Complètement gratuit
- Pas de frais
- Pas de configuration
- 50π fictifs pour tester

---

## ❓ Comment acheter un abonnement?

**Réponse:** 
```
1. /settings → Abonnement
2. Choisir PRO (5.99π) ou PREMIUM (19.99π)
3. Cliquer "Activer"
4. Approuver le paiement
```
