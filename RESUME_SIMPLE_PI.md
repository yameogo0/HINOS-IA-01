📊 MODE SANDBOX vs PRODUCTION

SANDBOX (DÉFAUT)
✓ Aucune configuration requise
✓ Argent fictif (50π)
✓ Transactions simulées
✓ Stockage local
✓ Parfait pour tester

PRODUCTION (OPTIONNEL)
• Clé API Pi requise
• Argent réel
• Transactions vérifiées
• Blockchain Pi Network
• 1-2% de frais
